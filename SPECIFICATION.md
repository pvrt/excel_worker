# Спецификация проекта: Excel Match, Search, Hash & Diff Tool

## 1. Общее описание

**Excel Match Tool** — это кроссплатформенное десктопное приложение на Python (Tkinter), предназначенное для автоматизации рутинных операций с файлами Excel (`.xlsx`), вычисления хеш-сумм и сравнения списков данных.

Интерфейс спроектирован с использованием вкладок (`ttk.Notebook`), все тяжелые операции чтения/записи выполняются в отдельных потоках (`threading`), что предотвращает зависание графического интерфейса.

---

## 2. Архитектура и стек технологий

* **Язык:** Python 3.10+
* **GUI-фреймворк:** Tkinter / `ttk` (нативный UI, встроенный в стандартную библиотеку Python).
* **Работа с Excel:** `openpyxl` (в потоковом режиме `read_only=True` и `data_only=True` для высокой производительности и экономии памяти).
* **Многопоточность:** Модуль `threading` со связью через GUI-колбэки (`lambda` / `after`).
* **Хеширование:** Стандартный модуль `hashlib` с блочным чтением (по 64 КБ).
* **Кроссплатформенность:** Поддержка Windows, macOS (`open`) и Linux (`xdg-open`).

## 3. Функциональные модули (Вкладки)

### Вкладка 1: Массовое сопоставление (Bulk Match)

**Назначение:** Поиск соответствий между списком идентификаторов из одного файла Excel и массивом файлов актов/документов в выбранной директории.

* **Входные данные:**
* Исходный Excel-файл со списком ID.
* Номер колонки с ID в исходном файле (1-based index).
* Директория с актами (рекурсивный поиск во всех подпапках).
* Целевая колонка для записи результата в исходный файл.
* Флаг наличия строки заголовков.
* Номер колонки для поиска внутри файлов папки (опционально: по конкретному столбцу или по всем ячейкам/листам).


* **Форматы извлекаемого результата:**
1. `last_number` — последняя группа цифр из названия файла (регулярное выражение `\d+`).
2. `full_filename` — полное имя файла (`act-123.xlsx`).
3. `filename_stem` — имя файла без расширения.
4. `relative_path` — относительный путь к файлу.
5. `row_cell_value` — значение из указанной колонки той же строки, где найден ID.
6. `fixed_row_value` — значение из фиксированной ячейки файла (заданная строка и колонка).


* **Выходные данные:** Новый Excel-файл с дополненной колонкой результатов (несколько совпадений объединяются через запятую с дедупликацией).

---

### Вкладка 2: Поиск по списку строк (Multi-Query Search)

**Назначение:** Быстрый поиск произвольного списка строк/УИНов по массиву Excel-файлов с возможностью пакетного копирования найденных файлов.

* **Функционал:**
* Многострочное поле ввода с поддержкой горячих клавиш (`Ctrl+V`, `Cmd+V`, русская раскладка) и контекстного меню.
* Разбор введенных данных по строкам и запятым.
* Рекурсивный поиск совпадений без учета регистра символов.
* Интерактивная таблица (`ttk.Treeview`) со столбцами: *Имя файла*, *Найденный текст*, *Подпапка*, *Полный путь*.
* Открытие файла в ассоциированном приложении (Excel) по двойному клику.
* Пакетное копирование всех найденных файлов в целевую папку (`shutil.copy2`).
* Экспорт списка путей в буфер обмена или `.txt` файл.



---

### Вкладка 3: Хеш-суммы файлов (Hash Calculator)

**Назначение:** Пакетный расчет контрольных сумм всех файлов в папке (и ее подпапках) с выгрузкой в Excel.

* **Функционал:**
* Поддерживаемые алгоритмы: **SHA-256**, **MD5**, **SHA-1**.
* Потоковое чтение файлов блоками по 64 КБ (безопасно для файлов большого объема).
* Исключение временных файлов Excel (начинающихся с `~$`).
* Генерация Excel-отчета с двумя колонками: **«Имя файла»** и **«Хеш-сумма (АЛГОРИТМ)»** с автоматической настройкой ширины столбцов.



---

### Вкладка 4: Сравнение колонок (Diff Tool)

**Назначение:** Сравнение данных из двух столбцов разных (или одинаковых) Excel-файлов и наглядное отображение различий.

* **Функционал:**
* Выбор двух файлов, номеров колонок и флагов заголовков.
* Вычисление трех множеств:
* *Только в Файле 1* ($A \setminus B$)
* *Только в Файле 2* ($B \setminus A$)
* *Общие значения* ($A \cap B$)


* **Режимы отображения:**
* **Side-by-Side Diff:** Табличный вид с подсветкой статусов строк цветом (зеленый — общее, красный — только в 1, оранжевый — только в 2) и фильтром «Только различия».
* **Фильтр по категориям:** Полноразмерный список выбранной категории.


* **Экспорт результатов:**
* Экспорт полного отчета в `.xlsx` (Лист 1: Построчный Diff, Лист 2: Списки по колонкам).
* Копирование и экспорт в `.txt`.

## 4. Особенности реализации и обработка данных

1. **Нормализация значений ячеек (`clean_val`):**
* Удаление неразрывных пробелов (`\xa0`).
* Приведение чисел с плавающей точкой вида `123.0` к строкам вида `'123'`.
* Удаление краевых пробелов.


2. **Буфер обмена и локализация в Tkinter:**
* Реализован универсальный перехватчик событий ввода для виджетов `tk.Text`, поддерживающий стандартные сочетания клавиш при активной русской раскладке клавиатуры (`Control-Cyrillic_em`, `Control-Cyrillic_es` и т.д.) и macOS (`<Command-v>`).


3. **Открытие файлов:**
* Определение платформы через `platform.system()`: использование `os.startfile` для Windows, `subprocess.run(["open", ...])` для macOS и `xdg-open` для Linux.

## 5. Сборка и развертывание

### Зависимости

```bash
pip install openpyxl pyinstaller

```

### Сборка под Windows (.exe)

```bash
pyinstaller --onefile --noconsole --name "ExcelMatchTool" app.py

```

*Исполняемый файл будет доступен в папке `dist/ExcelMatchTool.exe`.*

### Сборка под macOS (.app)

```bash
pyinstaller --windowed --onedir --name "ExcelMatchTool" app.py

```

*Бандл приложения будет создан в `dist/ExcelMatchTool.app`.*
